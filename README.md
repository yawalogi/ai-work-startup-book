# AIと長く仕事するための、小さな入門書

AIバックエンド受講者向けの静的Web小冊子です。HTML・CSS・最小限のJavaScriptのみで動作します。外部サービス、フォント、ライブラリへの通信はありません。

## ファイル

- `index.html`：全文を収めた公開ページ。JavaScriptが無効でも読めます。
- `assets/style.css`：本文、引用、プロンプト例、PC・スマートフォン・印刷用のスタイル。
- `assets/reading.js`：モバイル目次の折りたたみと現在の章の表示。
- `content/book.md`：完成原稿の正本。指定されたv02原稿と同一で、制作メモも保持しています。
- `scripts/build.mjs`：正本から公開HTMLを再生成する、依存パッケージ不要のNode.jsスクリプト。
- `robots.txt`：noindexを読めるようクロール自体は禁止しません。
- `.nojekyll`：GitHub PagesでMarkdownを別のHTMLページに変換しないための指定。

## 本文の更新

`content/book.md`を編集した後、リポジトリのルートで実行します。

```sh
node scripts/build.mjs
```

生成した`index.html`も原稿と一緒に保存・コミットしてください。公開サーバー側でのビルドやNode.jsは不要です。`index.html`の直接編集は再生成で上書きされます。

変換処理はこの原稿で使用している見出し、段落、引用、箇条書き、番号付きリスト、太字、インラインコード、区切り線に対応しています。汎用Markdownエンジンではありません。表・画像・リンクなど新しい記法を追加するときは変換処理も対応させてください。引用中のMarkdown記法の説明例は記号を残して表示します。

## 制作メモの扱い

初回生成では33件を公開HTMLから除外しました。「図解候補」「小さな図解候補」「メイン図解候補」「スクリーンショット候補」「吹き出し候補」の見出しから、その直後の区切り線までが対象です。配下の図のラベル、配置指示、「左：」「右：」「下に」なども同じブロックに含めて除外しています。再生成時に対象の行番号と見出しを表示します。

本文は要約・書き換えを行っていません。前後で重複する区切り線だけを一つにしています。プロンプト例、ミニケース、コラム、実践欄、人間とAIのやり取り、各章のまとめを保持しています。「Part 2」の表記も第6章の直前に保持しています。HTMLの見出し階層のみ、書名→章→節→小見出しに整えています。

## サイト構成

一つの長いページに、はじめに、第1〜7章、おわりにを掲載しています。

固定アンカーは`#intro`、`#chapter-1`〜`#chapter-7`、`#closing`です。メールでは、たとえば次のURLを案内できます。

https://yawalogi.github.io/ai-work-startup-book/#chapter-3

PCでは左側に目次を固定し、スマートフォンでは上部の折りたたみ目次を使います。各章末に前後の章へのリンクがあります。CSS・JavaScriptは相対パス、章リンクは同一ページ内アンカーなのでサブディレクトリ配信に対応します。

## GitHub Pages公開前の確認

1. 変更を確認し、公開するブランチへコミット・pushします。この制作ではpush・公開設定の変更は行っていません。
2. GitHubのSettings → Pagesで`Deploy from a branch`、公開ブランチ（通常`main`）、`/(root)`を選びます。
3. 公開後、トップと`#chapter-3`などの直接リンク、CSS・JavaScriptの読み込みを確認します。
4. PCと実際のスマートフォンで、横はみ出し、文字サイズ、目次の開閉、現在章の表示、章末リンク、キーボード操作を確認します。
5. ページソースの`<meta name="robots" content="noindex, nofollow">`を確認します。

公式手順：https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

検索除外は公開HTMLのmetaタグによります。プロジェクト配下の`robots.txt`はドメイン直下のrobots.txtとしては扱われません。クロールを禁止するとnoindexを読めなくなるためDisallowは設定していません。認証やアクセス制限ではありません。

ルート全体を公開する構成のため、URLを直接指定すれば`content/book.md`などのソースファイルも取得できます。制作メモは読書ページには掲載しませんが、原稿ファイルには残っています。
